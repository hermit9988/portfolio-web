# Label Guide

This directory documents the taxonomy and priority levels for issues and pull requests in this repository.

## Priority (`P0` → `P3`)

| Label | Meaning | Color |
|---|---|---|
| `🔴 P0` | Critical emergency: build crash, deployment outage, security leak, or broken live site | `#b60205` |
| `🟠 P1` | High priority: blocks planned work or major visual/functional flaw | `#d93f0b` |
| `🟡 P2` | Medium: normal priority bug or feature task | `#fbca04` |
| `🟢 P3` | Low: minor polish, cosmetic fix, or nice-to-have suggestion | `#1a7f37` |

## Type

| Label | Meaning |
|---|---|
| `🐛 bug` | Something isn't working as expected |
| `✨ enhancement` | New feature or visual improvement |
| `📚 documentation` | Improvements or additions to documentation |
| `❓ question` | Further information or clarification requested |
| `🙋 help wanted` | Extra attention is needed; contributions welcome |
| `🌱 good first issue` | Good for newcomers |

## Status

| Label | Meaning |
|---|---|
| `🚧 in progress` | Work is actively underway |
| `🧱 blocked` | Blocked by external dependency or pending discussion |
| `✅ ready to merge` | Approved and ready to merge |
| `🎉 merged` | Already merged into main |
| `🚫 wontfix` | Will not be addressed or out of scope |

## Areas

| Label | Meaning |
|---|---|
| `area: ui-ux` | Frontend visual design, responsive layouts, or styling |
| `area: content` | CV data, biography, research papers, or text copy |
| `area: deploy` | Cloudflare Pages, Workers, or Wrangler deployment |
| `area: assets` | Static images, pdfs, fonts, or media assets |

## PR Quality Rating (low → high)

| Rank | Label | Meaning |
|---|---|---|
| 1 | `rating: 🥉 bronze draft` | Initial draft or work-in-progress pull request |
| 2 | `rating: 🥈 silver polish` | Solid implementation needing final review or formatting pass |
| 3 | `rating: 🥇 gold master` | Production-ready changes passing all tests and build verification |
| 4 | `rating: 💎 diamond release` | Exemplary contribution, major feature, or milestone release |

> Maintained by `repo-standardizer` — keep in sync whenever labels change.
