# Security Policy

## Reporting a Vulnerability

Please **do not** open a public issue for security vulnerabilities.

Report privately instead:

- Open a [private security advisory](https://github.com/hermit9988/portfolio-web/security/advisories/new), or
- Contact the maintainer directly via GitHub profile: [@hermit9988](https://github.com/hermit9988).

Please include:
- Affected file / commit / component
- Clear steps to reproduce
- Potential impact description

## Supported Versions

| Version | Supported |
|---------|-----------|
| `main` (latest) | ✅ |

## Disclosure

We appreciate responsible disclosure. Once a fix is verified and deployed, acknowledgments will be credited appropriately.
